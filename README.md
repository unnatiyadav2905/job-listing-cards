# Job Listing Cards

A responsive job listing cards web application built using React, JavaScript, HTML, and CSS.

## Features

- Responsive job listing card layout
- Company logos and job information
- Job title and company name
- Job posting date
- Employment type
- Experience level
- Salary and location
- Save button
- Apply Now button

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
